# SimpleTracker v2: работа внешнего агента

Артём выбрал передачу данных Jira через API своего агента. Сам SimpleTracker не подключается к Jira или почте.

Полный контракт с примерами, правилами повторной доставки, временем событий, документами и согласованием находится в [api/agent-guide.txt](../api/agent-guide.txt). Это единственный исходник инструкции; API отдаёт этот же файл через `GET /integrations/guide`.

После установки v2 на сервер:

- инструкция: https://api.simpletracker.ru/integrations/guide;
- интерактивный контракт: https://api.simpletracker.ru/docs;
- схема OpenAPI: https://api.simpletracker.ru/openapi.json.

До установки нового backend эти адреса не подтверждают доступность новых функций. Наличие инструкции также не означает, что ключи интеграции настроены.

Нужны два отдельных доступа: `AGENT_API_TOKEN` для работы с задачами, событиями и документами; `JIRA_INGEST_TOKEN` для Jira-снимков и истории. Значения передаются только защищённым способом и не записываются в Git или сообщения.

Перед первой записью прочитайте задачу и каталог `/integrations/agent/options`. После записи перечитайте результат. Для повторной попытки используйте тот же `external_id` и то же содержимое. Ответ `409` требует сверки, а не замены идентификатора ради обхода ошибки.

Почтовые правила остаются у агента. Старый `/integrations/mail/events` сохранён; не передавайте одно действие одновременно в старый и новый маршруты. Запись события и явное изменение статуса — разные операции. Не выводите согласование новой версии из согласования старой.
